# 我在末日独自生存

竖版末日生存挂机 RPG。**9:16 竖屏 + 过肩第三人称**，主角自动战斗，
从下水道打老鼠开始，逐场景推进到太平洋深渊。

- **100 关 / 10 个场景**，可完整通关
- **三条修炼路线**：体术 / 枪械 / 异能，换武器 = 换流派
- **每场景第 10 关**是 Roguelike 割草 Boss 战（三选一强化 + 生存压力）
- 装备掉落 / 随机属性 / 强化 / 套装 / 宠物 / 科技树 / 离线挂机

## 怎么玩

直接打开 `index.html` 就能玩 —— **无构建步骤、无外部依赖、无网络请求**。

也可以挂在任意静态服务器上：

```bash
python -m http.server 8000   # 然后访问 http://localhost:8000
```

> 双击 `index.html` 时（`file://`）浏览器可能禁止 `localStorage`，
> 表现是提示"无法保存进度"。开个本地服务器即可。

**布局随屏幕宽度自适应**：
- 宽屏（>1180px）：左竖排按钮栏 │ 中间 9:16 竖版画布 │ 右侧面板停靠栏
- 窄屏（≤1180px，含手机）：画布铺满整屏，按钮做成半透明悬浮在画面上

## 目录

```
index.html          入口，按顺序加载全部脚本
css/                base(变量) / layout(布局) / panels(面板与浮层)
js/data/            纯数据表：场景/怪物/装备原型/武器/科技/词条/配置
js/core/            逻辑：战斗/割草关/背包/属性/宠物/状态/音效/公式
js/ui/              界面：渲染/精灵/面板/特效/音频文件层
assets/             贴图与音频（按数据表 ID 命名，一一对应）
```

## 说明

- 音效是**合成打底 + 音频文件覆盖**：38 个程序化合成音效零素材可用，
  补一个音频文件就自动覆盖同名的那一个
- 存档在浏览器 `localStorage`，换浏览器/清缓存会丢
- 美术素材由设计者提供
