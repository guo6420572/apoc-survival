# 《三国·将星录》V1 长线运营版（本地正式版）

按 V1 长线运营案搭建：主城、招募抽卡、商城、将星塔、副本、秘境、上古副本、赛季、体力、编队、手动/自动战斗、养成、图鉴与本地存档。

## 启动

```bash
cd G:\桌面\个人文件\项目\三国将星录\正式版
~/opt/venv-learn/bin/python server.py
```

浏览器打开：**http://localhost:8790**

Windows 也可以双击 `启动正式版.bat`（会启动 WSL 服务并打开浏览器）。

## 临时公网链接（给朋友试玩）

```bash
cd G:\桌面\个人文件\项目\三国将星录\正式版
bash 启动公网链接.sh
```

脚本会确保 8790 在运行，并用 Cloudflare 快速隧道生成 `https://xxxx.trycloudflare.com` 公网地址，同时写入 `公网链接.txt`。

- 链接是**临时**的：电脑关机、WSL 关闭或隧道断开后失效；重新运行脚本会生成新链接。
- 任何拿到链接的人都能直接访问，不需要账号；不要在公开场合传播。
- 停止公网访问：`pkill -f "cloudflared tunnel --url http://localhost:8790"`（本地 8790 不受影响）。

## 内容

- **主城**：体力、货币、14 个入口（征战/招募/商城/将星塔/副本/秘境/上古/赛季/武将/养成/图鉴/任务/剧情/游历）

- **体力**：测试版上限 10000（初始补满 10000）、6 分钟 +1、每日两次领取、关卡/副本/秘境消耗

## 已知限制

- 副本仍是简化实现；秘境已加节点与商店，暂未做临时招募；上古已支持 8 人编队（同一战场，非两队独立结算）。
- 主线每章第 1/5/10 关为固定阵容（按章节确定性生成），其余 7 关仍是程序生成。
- 等级仍是全局设置，突破/觉醒已经逐将；付费档位（月卡/战令）未接支付，只在设计层保留。
- 700 关中仅每章第 1/5/10 关固定，其余为程序生成；个别关卡有时代错位。
- TTK 已专项平衡：伤害系数改用一级基础属性、减伤等级项 30→5、兵力按等级补偿、第 7 回合起每回合 +14% 战意增伤；均衡 5v5 约 Lv1 12.4、Lv30–100 9.7–10.6 回合。怒气参考三国志战略版节奏（初始 20，普攻 +40、受击 +20）。
- 特色/被动已接入 105/105 条（团队减伤/回血、条件增伤、召唤、复活、主将代伤、人数条件、随机 buff、兵种互克等）；少数为近似实现，见 `模拟器/天赋机制说明.md` 第六节。
- 436 条天赋已全部接入结算；伤害传递（连环）、复制战法、自损、死斗均已实现，剩余近似项见 `模拟器/天赋机制说明.md`。
- 存档默认只在浏览器 localStorage，没有账号系统；换浏览器会丢，需用设置页的导出/导入手动迁移。
- 音频为 WebAudio 程序合成的基础 BGM、点击音效与逐将签名音，无外部配乐素材；场景仍以卡面/立绘与程序化背景为主。
- 数值平衡仍有余量：调参后 5v5 胜率 sd≈0.136，仍有约 15 人在 ±0.25 之外；羊祜/朱灵/曹丕等头部与逢纪/关兴/关平等尾部待继续调，郭嘉/关平的角色错位更适合改套件而非数值。
- 模拟器已同步正式版引擎与物品结算，但跑分仍是 Lv1/0 突破/0 觉醒的无物品基线，不代表高等级与满装备环境。
- WebP 派生图在 `正式版/img/`（不进快照）；重绘卡面后需重跑 `tools/make_webp.py`，图片缓存 1 天，必要时清浏览器缓存。
