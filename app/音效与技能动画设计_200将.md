# 《三国·将星录》200 将 特色音效与技能动画设计

生成于 2026-11-21　｜　覆盖 200/200 名武将

## 一、设计原则

**音效按兵种分族，物理写实、法术玄幻**：步兵用钝击与刀剑金属，骑兵用马蹄与气劲，弓兵用弓弦与箭矢破空；方士用低频吟鸣与钟磬和声，法术形态再叠加火、雷、毒雾、气旋等玄幻层。

**每人三层叠加，逐人不同**：兵种族层 + 技能形态层 + 个人签名层。基频由六维属性加权算出（武勇拉低、机变与天命拉高），再按 ID 哈希微调 ±6%，保证同兵种 40 余人彼此能听出音高与质感差异。

**动画 13 形态 + 5 种玄光子型**，形态由特色技语义与兵种决定，配色取阵营主色，强度按稀有度分四档（粒子量、光环半径、震屏等级）。

- **引擎**：`web/hero_show.js`（IIFE，挂 `window.HeroShow`），对外 `profile / cast / hit / heal / control / death / setQuality / clear / debugPlay`。
  - 音色表 `LAYER` 共 29 种：impact / hoof / twang / metal / whoosh / arrow / iron / bone / chain / wood / water / wind / flag / horse / rumble / chime / choir / grace / fire / spark / whisper / poison / ice / roar / beast_roar / zither / paper / bell / gong。

  - 三层音色的音高按 `hash(id|特色技)` 再偏 ±7%，层间隔 ×0.75–1.25，整体音量 ×0.90–1.18。

## 6.2 阵营染色层（2026-11-21）

200 将共用 13 张形态贴图，只靠形态本身很难看出阵营。为此给每个形态再派生 4 张"阵营色版本"。

- 取色：魏 `#3A6CA8` / 蜀 `#B23A2E` / 吴 `#2E8A6A` / 群雄 `#7A4A9E`（`p.col` 即阵营色，每阵营唯一）。
- 生成 `tintOf(im, form, col)`：离屏 256×256，先画原图打底，再以 `globalCompositeOperation='color'` 填阵营色（保留原图明暗与高光），最后 `destination-in` 用原图 alpha 收边。缓存键 `form|col`，上限 13×4=52 张、约 13MB。
- 合成：loop 内原图先按 `lighter` 画（发光），染色层随后**必须切回 `source-over`** 以 `al*0.92` 覆盖。若留在 `lighter` 里叠加，只会越叠越亮，色相等于没换。
- 效果：魏=蓝紫、蜀=绛红、吴=青绿、群雄=紫，白色高光不受损。同一张刀气在四阵营下是四种可辨认的光。

验证：离线 `tools\preview_tint.py`（HLS 保亮度换色相复现 `color` 语义）输出四阵营对照，实机确认魏色刀气染色正确（旧抓帧已清理）。
